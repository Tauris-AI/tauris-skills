# Tauris Skill Areas

This catalog groups the repo by petroleum workflow. Each area owns its skills, MCP servers, setup guide, references, and scripts.

## Areas

- `aries` - ARIES concepts, Access table contracts, and economic table review.
- `phdwin-v2` - read-only PHDWin v2 inspection, native extraction, and review exports.
- `phdwin-to-aries` - conversion-readiness review from PHDWin source data into Aries-ready artifacts.
- `petroleum-economics` - general reserve and economics review workflows.

## Packaging Rule

Area folders should contain orientation and routing docs plus the implementation files needed for that workflow. Keep generated client data, extracted databases, and local review outputs out of git.
