# PHDWin To Aries Reference Pack

This folder contains conversion reference material copied from `Tauris.PhdWin` so the Cowork MCP package has the context needed for PHDWin-to-Aries review.

## Included

### Tauris-authored Markdown

- `tauris-phdwin-docs/PHDWIN_DATA_MAP.md`
- `tauris-phdwin-docs/ARIES_ACCESS_TABLE_CONTRACTS.md`
- `tauris-phdwin-docs/ARIES_ACCESS_EXPORT_PLAN.md`
- `tauris-phdwin-docs/ARIES_SCHEMA_MAPPING.md`
- `tauris-phdwin-docs/ARIES_AC_PROPERTY_RULES.md`
- `tauris-phdwin-docs/ARIES_CODEBASE_INVENTORY.md`
- `tauris-phdwin-docs/ARIES_EXPORT_RUNNING_LIST.md`
- `tauris-phdwin-docs/ARIES_MIGRATION_ROADMAP.md`
- `tauris-phdwin-docs/LLM_DATABASE_DIAGNOSTIC_PROFILE.md`
- `tauris-phdwin-docs/ARIES_CONVERSION_NEXT_STEPS.md`

### Templates

- `templates/Aries_Template.accdb`

The template is intentionally committed as reference material. Do not replace it with a client database.

## Excluded

The package intentionally excludes raw/sample databases and third-party/vendor documents from `Tauris.PhdWin/docs/reference-inputs`, including large `.mdb`, `.accdb`, `.pdf`, `.chm`, `.docx`, and `.xlsx` reference files, unless they are explicitly cleared for redistribution.

Do not commit client PHDWin files, generated SQLite exports, extracted source folders, or generated reports.
