# PHDWin to Aries

PHDWin-to-Aries conversion review, mapping, and handoff support.

## Included Assets

- MCP server: `mcp-servers/PHDWin_to_Aries_MCP`
- Playbook: `mcp-servers/PHDWin_to_Aries_MCP/PHDWIN_TO_ARIES_PLAYBOOK.md`
- Table map: `mcp-servers/PHDWin_to_Aries_MCP/PHDWIN_TO_ARIES_TABLE_MAP.md`
- Tauris conversion references: `mcp-servers/PHDWin_to_Aries_MCP/reference/tauris-phdwin-docs`
- Aries Access template: `mcp-servers/PHDWin_to_Aries_MCP/reference/templates/Aries_Template.accdb`
- Setup guide: `SME_SETUP_GUIDE.md`

## Scope

This area is for Claude Cowork users to inspect source data, review conversion readiness, understand PHDWin-to-Aries mapping, and produce named review artifacts.

It does not replace the production converter. Final Access export logic remains in `Tauris.PhdWin`, while this package exposes the workflow knowledge and reference data needed for review and consulting handoff.
