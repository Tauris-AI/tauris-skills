# Petroleum Economics Local E2E Workspace

Use this folder for local end-to-end petroleum economics review tests.

Everything in this folder is ignored except this README. Good candidates:

- cleared economic case summaries
- local review memos
- model excerpts
- prompt transcripts
- generated diligence checklists
- screenshots and logs

Suggested smoke flow:

1. Load the `petroleum-economics-review` skill in the target AI workflow.
2. Place cleared economic inputs or summary excerpts in this folder.
3. Run a review prompt against the skill.
4. Confirm the output separates facts, assumptions, risks, and follow-up checks.
5. Do not place customer confidential data here unless the local machine and repo policies allow it.
