# Tauris Petroleum Domain

Use this plugin entry skill to route petroleum engineering requests to the right curated workflow.

## Routing

- Use `aries-core` concepts when the task involves ARIES broadly.
- Use `aries-ac-economic` when the task involves `AC_ECONOMIC` table lines.
- Use `phdwin-querying` when the task involves PhdWIN database reads or query drafting.
- Use `petroleum-economics-review` when the task involves economics assumptions, outputs, or sanity checks.

## Safety

Do not store or request secrets, raw production exports, license keys, or connection strings. Require dry-run review before any mutation workflow.
