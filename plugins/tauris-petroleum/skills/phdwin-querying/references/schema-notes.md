# PhdWIN Schema Notes

This file should hold curated, sanitized schema notes for PhdWIN databases.

## Curation Inputs

- Database version or application context.
- Sanitized table and column lists.
- Common joins.
- Key identifiers for wells, leases, cases, forecasts, and economics outputs.
- Known customer-specific customizations, with customer identifiers removed.

Do not store raw production schema exports if they include sensitive names or connection details.
